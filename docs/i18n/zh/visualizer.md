# Visualizer

Visualizer 将 EffeTune 处理后的声音呈现为可自定义的图表，并可加入封面和曲目信息。调整画面不会改变声音。

## 打开与放大

在电脑布局中，点按顶部的 **Visualizer**；在移动端，从 **播放器** 标签页打开；桌面应用还可使用 **视图 > Visualizer**。你也可以在 **配置...** 中将它设为启动视图。内置预设按 16:9、21:9、4:3、1:1 和 9:16 分类。选择预设会替换当前布局。图表显示经过效果处理、即将送往音频输出的信号。

每种画面比例提供 8 种设计，共 40 个布局。**Stereo Workbench** 用于比较左右声道，**Phase & Level** 侧重立体声位置和电平。**Frequency Timeline** 与 **Transient Lab** 帮助观察频率成分随时间的变化；**Harmonic Atlas** 与 **Practice Roll** 展示检测到的音符活动。**Album Cinema** 和 **Pulse Geometry** 则侧重音乐的视觉呈现。

将指针移到画面上或轻点画面，即可显示 **⛶**。点击后，画面会保持比例并铺满应用窗口，边缘可能被裁切。再次点击 **⛶**、按 **Esc** 或使用移动端返回操作即可退出。桌面应用在 Visualizer 打开时切换到 Mini Player，会在播放控件上方显示画面。

## 编辑布局

选择 **Edit**。修改会立即显示，下次启动 EffeTune 时也会恢复。要保留有名称的副本，请在预设对话框中选择 **保存**；仅编辑布局不会覆盖已保存的预设。

编辑时，左侧显示整体设置、项目列表和**画质**，中间是画布，右侧是所选项目的设置。

- 选择画面比例、背景颜色或背景图片；导入的大图会缩小。可添加 **Oscilloscope**, **Spectrum**、**Spectrogram**、**Stereo**、**Level Meter**、**Notes**、**Chroma Spiral** 图表以及 **Artwork**、**Title**、**Album**、**Artist**。拖动项目可移动位置，拖动四角可调整大小。网格吸附有助于对齐，前移与后移控件可调整叠放顺序。 选中项目后按 Ctrl+D（Mac 上为 Cmd+D）可复制并移动一个网格单位；按住 Alt 拖动可直接创建并放置副本。
- 在**主题颜色**中，可以调整此布局的图表基底色、浅色图表填充、细网格和主网格、图表标签、坐标轴标题及仪表刻度，而不改变音频信号的调色板。未修改的颜色使用默认深色主题的颜色，不受当前 EffeTune 主题影响。选择**使用默认颜色**可恢复默认配色。
- 图表可选择音频通道。默认使用输出通道 1–2；选择单个通道时，会在两侧显示同一信号，但 Level Meter 只显示一根条形。也可水平或垂直翻转。
- **颜色模式** 初始为 **纯色**，可用独立的颜色选择器设定颜色。添加新项目时，纯色初始值取自默认深色主题的图表绘制色。**渐变** 可调整色标，也可从 23 种预设中选择。**Hue** 会随时间改变渐变色相，**Scroll** 会移动渐变；两者都可调整速度。切换模式时，纯色和渐变设置都会保留。
- 在 **项目** 中调整各个图表。**Title**、**Album** 和 **Artist** 的文字可分别设置字号、字体、对齐方式、**加粗**和**斜体**。如果设备或浏览器无法使用所选字体，将改用其他字体。封面可使用圆角。下面介绍图表控件。

## 阅读和调整图表

**Spectrum** 按频率显示电平，最近的峰值会逐渐回落。**方向**在默认的**水平**布局中让频率从左到右排列；切换为**垂直**后，低频在下、高频在上，键盘移至左侧，电平越高越向右延伸。**显示方式** 可在 **线条** 与 **柱状** 之间切换。在**柱状**模式下，默认开启的**量化**会把柱高对齐到完整区块，并用一个区块显示峰值；测得的电平不变。增加 **采样点数** 能分开相近的频率，但响应会变慢。**频率刻度** 提供 **对数**、更细致分析低频的 **对数（HQ）**，以及让相同频率间隔占相同空间的 **线性**。把 **dB 范围** 设为更小的负值，可以看到更微弱的声音。**键盘** 可添加音符参考。**坐标轴与网格** 和 **坐标轴标签与数值** 只改变辅助线的显示。这两项和 **键盘** 初始关闭。

**Spectrogram** 纵向排列频率，让新的测量结果随时间横向滚动。较强的频段在所选调色板中更醒目。**采样点数**、**频率刻度**、**dB 范围**、**键盘** 和坐标轴控件与 Spectrum 的作用相同。初始设置为 **对数（HQ）** 和 4096 点。增加点数可以看到更多细节，但声音变化会稍晚显示出来。

**Stereo** 将左右声道一起绘出。轨迹和峰值轮廓反映声像宽度与电平；相关性和平衡指示器帮助判断两个声道有多相似、哪一侧更强。**窗口** 控制显示最近 10 至 1000 毫秒的声音。较短的窗口更容易跟随瞬态，较长的窗口更稳定。坐标轴控件可显示或隐藏参考线。 **相关性** 和 **平衡** 可分别显示或隐藏这两个指示器。

**Level Meter** 默认用 −96 至 0 dB 的条形显示各声道电平。**dB 范围**可将显示下限设为 −144 至 −48 dB，默认值为 −96 dB。**方向**可将默认的**水平**条形切换为**垂直**。细线会保持最近的峰值一秒，**OVERLOAD** 会在削波后警示五秒。**坐标轴与网格**控制 dB 参考线，**坐标轴标签与数值**控制其数值。**电平数值**可单独显示保持的峰值读数。这三项默认关闭，但 **OVERLOAD** 仍会显示。条形颜色可选择**纯色**、**渐变**或**热力图**。

**Oscilloscope** 按时间绘制所选声道捕获的波形。横轴表示毫秒时间，纵轴表示振幅。**显示时长**设置 1–100 ms 的可视范围（默认 10 ms）：较短的时间可观察短暂变化，较长的时间可显示更多波形。**触发模式**默认为**自动**，即使没有触发也会更新；**正常**会保持最近的波形，直到信号沿选定的**触发沿**方向穿过**触发电平**。触发电平范围为 −1 至 1（默认 0）；触发沿可选**上升沿**（默认）或**下降沿**。**触发保持时间**设置触发间最短时间，范围 0.1–10 ms（默认 0.1 ms）。**显示电平**设置 −96 至 0 dB 的垂直刻度（默认 0 dB）；较低的值会让较小振幅的波形显示得更大。**垂直偏移**将波形上下移动，范围 −1 至 1（默认 0）；正值上移，负值下移。**坐标轴与网格**和**坐标轴标签与数值**控制参考线和标签，默认均关闭。若波形不稳定，可使用重复声音并调整触发电平和方向。波形仅供观察，不是精确测量工具。

Spectrum、Spectrogram 和 Stereo 的 **输入增益** 只调整送入该图表的信号，范围为 −24 至 +24 dB，不改变播放声音。先从 0 dB 开始；想观察较弱的信号时提高增益，图形贴近上限时则降低增益。

**Notes** 随时间显示检测到的音高。**音高分辨率** 可选择按半音排列的 **1/12 八度**，或更精细的 **高精度（1/60 八度）**。**布局** 改变历史的方向，**显示时长** 控制可见的 1 至 10 秒历史。**音量** 在音高检测可信度之外显示音符电平。**最低音** 和 **最高音** 限定分析音域；**同时识别音符上限** 控制一次考虑多少个候选音符。如果无关音符挤满图表，可缩小音域或降低上限。**键盘** 用来显示钢琴琴键。键盘和坐标轴参考线初始关闭，可分别开启。使用 **渐变** 时，**完整音域** 将颜色分布到可见音高，**一个八度** 按音名重复颜色。

**Chroma Spiral** 将检测到的音符排列成螺旋，每圈代表一个八度。**显示方式** 可切换 **Dots** 和 **Fill**；**最低八度** 与 **最高八度** 决定范围。**频率倾斜** 调整不同频率的强调程度，**电平范围** 改变较弱音符的可见程度，**显示下限** 隐藏更弱的音符。

Spectrum 和 Chroma Spiral 的 **颜色模式** 均提供固定的 **音符颜色** 和 **热力图**。Spectrogram 提供 **热力图**，Notes 提供 **音符颜色**。十二种音符颜色每个八度重复一次，不随时间变化；Spectrum 中相邻音符的颜色平滑过渡。 在 Spectrum 的 **柱状** 显示中，每根柱子根据中心频率使用单一颜色。热力图用更亮的颜色显示较强的声音，并让较弱部分透明，而非涂成黑色。Stereo 和文字项目仅提供纯色和渐变。

## 动画与效果

给项目或背景添加效果，并调整顺序。**强度** 控制强度。**Opacity** 控制透明度，配合动画可做出闪烁。**Glow**、**Outline** 和 **Blur** 可突出或柔化图形。**Trail** 留下残影，**Trail Feedback** 可改变残影大小并使其旋转、移动。**Scale Pulse** 改变大小，**Symmetry** 重复图形，**Shake** 使图形晃动，**Particles** 添加移动的光点。**Ken Burns** 缓慢移动封面或背景图，**Flash** 让背景闪亮。

在 **Trail Feedback** 中，**旋转角度（°）**（−3°至+3°） 决定每次叠加的残影如何旋转：正值为顺时针，负值为逆时针，0° 不旋转。**水平流动** 的正值向右、负值向左；**垂直流动** 的正值向下、负值向上。组合两项即可让残影斜向移动。两项滑块均可在物件宽度或高度的 −1% 到 +1% 之间调整，0% 表示该方向不移动。**缩放** 可使每次叠加的残影缩小或放大 −2% 到 +2%：正值放大，负值缩小，0% 保持大小不变。初始值为 +2%。**强度** 也会影响缩放、旋转和移动的幅度。

效果可以保持固定，也可以随 **Time** 变化，或响应整体 **Level** 与低频 **Bass**。**响应幅度** 控制响应幅度，**速度** 控制随时间变化的速度。建议先添加一个强度较低的效果，例如给 Spectrum 加 Glow，再给 Artwork 加随 Bass 变化的 Scale Pulse。如果动画变慢，可减少效果或降低画质；**Auto** 会自动调整画质。

## 预设、备份与同步

在预设对话框中可保存、加载、重命名或删除有名称的布局。内置预设始终保留。**备份 / 恢复** 包含已命名的 Visualizer 预设及其背景图片，但不包含当前未命名的工作布局。Effect Pipeline 的分享链接也不包含 Visualizer 布局。

在 **设置** 中开启 **将画面与音频同步**，可让画面与听到的声音对齐；EffeTune 可能因此延迟声音。如果图表无法显示，请打开 **音频设置**，确认 **使用 WebAssembly 音频处理** 已开启，并检查声音是否经过 EffeTune 播放。

桌面版默认开启 **使用硬件加速**。如果应用窗口闪烁或画面停止更新，请在 **设置 > 配置...** 中关闭此选项，然后重启 EffeTune。如果显示问题反复出现，EffeTune 会自动关闭此选项并重新启动。若要再次尝试，请重新开启并重启应用。
